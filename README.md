# Timecheck · 합격 기록장

공무원 시험 준비를 위한 React 기반 학습 기록 웹앱입니다. 노트북에서 먼저 바로 사용할 수 있고, 화면 크기에 맞춰 휴대폰에서도 동작합니다.

GitHub 저장소: https://github.com/Yanghj3119/Timecheck

## 인터넷 없이 미리 보기

`오프라인 미리보기.html`을 더블클릭해서 브라우저에서 열면 됩니다. 설치나 인터넷 연결 없이 화면을 둘러보고 공부 기록과 강의 진도를 입력할 수 있습니다. 입력한 내용은 오프라인 미리보기를 여는 브라우저에 따로 저장됩니다.

## 시작하기

1. [Node.js](https://nodejs.org/) LTS를 설치합니다.
2. 이 폴더에서 `npm install`을 실행합니다.
3. `npm run dev`를 실행하고 터미널에 표시되는 주소를 브라우저에서 엽니다.

공부, 이동, 강의 진도 기록은 현재 사용 중인 브라우저에 자동 저장됩니다. 휴대폰 홈 화면에 설치해 앱처럼 사용할 수 있습니다. 브라우저의 사이트 데이터를 지우면 로컬 기록도 삭제될 수 있으니, 설정 화면에서 백업 파일을 내려받아 보관할 수 있습니다.

## GitHub와 Vercel 배포

Vercel에서 `Yanghj3119/Timecheck` 저장소를 가져오면 됩니다. Framework Preset은 Vite, Build Command는 `pnpm run build`, Output Directory는 `dist`로 설정합니다. 환경변수가 없어도 앱은 기기 저장 방식으로 열리지만, Supabase 동기화에는 아래 환경변수가 필요합니다.

## Supabase 확장

Supabase에 실행할 SQL 파일은 [`supabase/schema.sql`](supabase/schema.sql)입니다.

1. Supabase 대시보드에서 프로젝트를 열고 **SQL Editor → New query**를 선택합니다.
2. `supabase/schema.sql` 파일 전체를 복사해 붙여넣고 **Run**을 누릅니다.
3. `study_sessions`, `travel_routes`, `study_courses` 테이블과 로그인 사용자별 RLS 정책이 만들어집니다.
4. 이미 기본 SQL을 실행했다면 `supabase/sync_migration.sql`도 SQL Editor에서 실행해 로컬 식별자와 강의 연결 열을 추가합니다.
5. Vercel 프로젝트 Settings → Environment Variables에 다음 값을 등록하고 새 배포를 만듭니다.

```text
VITE_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY
```

값은 Supabase Project URL과 Publishable key입니다. 브라우저 앱에는 publishable key만 사용하고 `service_role`이나 secret key는 넣지 마세요.

앱의 **설정 → 기기 간 기록 동기화**에서 **새 계정 만들기**를 선택한 뒤 이메일과 비밀번호(8자 이상)를 입력합니다. 이메일 확인이 켜져 있으면 받은 확인 링크를 열어 가입을 마칩니다. 이후에는 이메일과 비밀번호로 로그인합니다. 비밀번호를 잊으면 **비밀번호 잊어버렸어**에서 재설정 메일을 요청할 수 있습니다.

Supabase **Authentication → URL Configuration**의 Redirect URLs에 실제 배포 주소 `https://timecheck-1ztj.vercel.app/**`를 추가하고 Site URL은 `https://timecheck-1ztj.vercel.app`으로 설정하세요. 로컬 개발도 쓴다면 `http://localhost:5173/**`도 허용 목록에 추가합니다. 이메일 확인 및 비밀번호 재설정 링크는 등록된 주소로 돌아옵니다.

Supabase 기본 이메일 발송기는 프로젝트당 시간당 2통으로 제한되며, 비밀번호 가입 확인과 재설정 메일도 이 제한에 포함됩니다. 한도 오류가 나면 한도가 풀릴 때까지 기다리거나 Custom SMTP를 설정하세요.

처음 로그인하면 현재 브라우저의 공부 기록·강의 진도·이동 경로를 계정에 합쳐 저장하고, 이후 기록은 Supabase와 동기화됩니다. 다른 기기에서도 같은 이메일로 로그인하면 기록을 불러옵니다. 로그인하지 않았거나 환경변수가 없으면 브라우저 저장 방식으로 계속 사용할 수 있습니다.
