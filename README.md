# Timecheck · 합격 기록장

공무원 시험 준비를 위한 React 기반 학습 기록 웹앱입니다. 노트북에서 먼저 바로 사용할 수 있고, 화면 크기에 맞춰 휴대폰에서도 동작합니다.

GitHub 저장소: https://github.com/Yanghj3119/Timecheck

## 인터넷 없이 미리 보기

`오프라인 미리보기.html`을 더블클릭해서 브라우저에서 열면 됩니다. 설치나 인터넷 연결 없이 화면을 둘러보고 공부 기록과 강의 진도를 입력할 수 있습니다. 입력한 내용은 오프라인 미리보기를 여는 브라우저에 따로 저장됩니다.

## 시작하기

1. [Node.js](https://nodejs.org/) LTS를 설치합니다.
2. 이 폴더에서 `npm install`을 실행합니다.
3. `npm run dev`를 실행하고 터미널에 표시되는 주소를 브라우저에서 엽니다.

공부, 이동, 강의 진도 기록은 현재 사용 중인 브라우저에 자동 저장됩니다. 휴대폰 홈 화면에 설치해 앱처럼 사용할 수 있습니다. 브라우저의 사이트 데이터를 지우면 로컬 기록도 삭제될 수 있으니, 설정 화면에서 백업 파일을 내려받아 보관할 수 있습니다.

## 현재 기본 계획

- 시험 목표: 2027 제주 지방직 9급 일반행정
- 주간 순공 목표: 평소 50시간 (월·화·수 6시간, 목·금·토 9시간, 일요일 5시간)
- 월요일부터 수요일까지 20:00–24:00 편의점 근무
- 2026년 11월 9일은 16:00–20:00 추가 근무 후 기존 20:00–24:00 근무
- 2026년 11월 20일은 16:00–20:00 추가 근무. 해당 주는 목·토 10시간, 금 7시간으로 50시간을 맞춤
- 2027년 시험 필기 과목: 국어, 영어, 행정법총론, 행정학개론(지방행정 포함). 영어 매일 학습
- 한국사는 3급 이상 한국사능력검정시험으로 대체되므로 별도 공부과목에서 제외
- 주간 과목 배분: 영어 13시간, 국어 8시간, 행정법총론 14.5시간, 행정학개론 14.5시간
- 영어 매일 학습, 일요일 주간 복습
- 이동시간은 순공부 시간과 분리 기록
- 강의 1강을 약 1시간으로 계산하고, 강의 완료 시 공부 기록에 자동 반영
- 출발 대화에서 확인된 도보 이동값: 집→탐라도서관 9분, 도서관→편의점 13분, 편의점→스터디카페 13분, 스터디카페→집 2분

## GitHub와 Vercel 배포

저장소에 이 폴더의 파일을 올린 다음 Vercel에서 저장소를 가져오면 됩니다. Framework Preset은 Vite, Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. 이 초기 버전은 Supabase 키 없이도 사용할 수 있습니다.

## Supabase 확장

현재 브라우저 간 동기화와 로그인은 아직 연결되지 않았습니다. Supabase 프로젝트를 연결할 때 사용할 SQL은 `supabase/schema.sql`에 있습니다. 사용자 인증과 사용자별 데이터 접근 정책을 먼저 적용한 다음, 프로젝트 URL과 공개 anon 키를 환경 변수로 연결하면 여러 기기 간 동기화를 추가할 수 있습니다. 서비스 역할 키는 브라우저에 넣지 마세요.
